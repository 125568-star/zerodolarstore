# Zero Dollar Store

The Zero Dollar Store website: an Australian marketplace for $0 items and local collection.

- Website domain: https://zerodollarstore.com
- Main site file: `index.html`
- GitHub Pages configuration: `.nojekyll` and `CNAME`
- Database and accounts: Supabase (the existing Zero Dollar Store tables and storage)

This is the dedicated repository under the `125568-star` GitHub account. The website is not published from this repository until GitHub Pages and domain DNS are configured.
